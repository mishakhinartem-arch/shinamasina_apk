# «Шинамашина» — веб-версия кассы (демо-прототип)

Демо-версия, **данные вымышлены**. Всё хранится в `localStorage` браузера (ключ `shinamashina_web_demo_v1`).
Реальный Supabase, APK, Эвотор и данные клиентов не используются. SMS нет.

## Страницы
| Файл | Что это |
|---|---|
| `index.html` | Касса (планшет Teclast M50, горизонтально; терпимо в портрете и на телефоне) |
| `owner.html` | Страница владельца для iPhone: отчёты, прибыль, ЗП за открытую смену (по PIN) |
| `book.html` | Онлайн-запись для клиентов |
| `client.html` | Анкета клиента с согласием на ПД |

Демо-PIN владельца: **1234** (подсказка показана на экране ввода). Сброс: Админка → Настройки → «Сбросить демо-данные».
Запуск локально: `python3 -m http.server 8765` в этой папке → http://localhost:8765/ . После первой загрузки по https работает офлайн (service worker).

## Модули (переносятся в APK/WebView как есть)
Логика без DOM (`js/`): `core` (время, формат, госномер), `store` (состояние), `prices-data` (= prices.js из кассы 14.7), `prices` (каталог, «Частые»),
`cart` (надбавка +20%, скидки, лимит), `orders` (заказы и статусы), `shift` (смена, ящик, инкассация), `payroll` (ЗП, расчётный лист),
`warehouse` (склад, нормы, автосписание; грузики — коробками), `storage` (хранение шин, тариф), `booking` (запись, очередь), `reports` (расходы, отчёты, прибыль), `excel` (прайс ⇄ xlsx), `seed` (демо-данные), `docs` (сгенерирован из `docs/*.md`: договор хранения и согласие на ПД), `consent`.
Интерфейс (`ui/`): `base` (окна, клавиатура госномера, нумпад, PIN, печать), `kassa`, `shift`, `clients`, `storage`, `warehouse`, `bookings`, `admin`, `report-view`.
SheetJS лежит локально: `vendor/xlsx.full.min.js`.

## Решения Артёма (18.11.2026), внесены
1. Скидка постоянному 10% не входит в лимит — лимит только на ручную скидку кассира.
2. Хранение — фиксированный тариф (Админ → Настройки → «Хранение — тариф»): ₽ за комплект 4 шины за сезон (6 мес.) по радиусу + доплата за диски; другой срок / число шин — пропорционально, до 50 ₽. **Демо-значения примерные.** При приёме цена подставляется сама; изменить вне тарифа — только по PIN. Хранение можно добавить в чек заказа: скидки (постоянному и ручная) на него не действуют.
3. Хранение не входит в базу процента мастеров (и в «Услуги» в отчётах — идёт отдельной строкой).
4. Грузики (набивные и клеевые) не списываются по нормам с машины — учёт коробками: приход коробками, «📦 Выдать коробку» (списание целой коробки), инвентаризация в коробках.
5. Договор хранения и согласие на ПД — **шаблоны, юристом не проверены**: в акте/печати хранения, в анкете `client.html`, в `book.html` и в форме клиента (раскрывающийся полный текст).

Старые демо-данные в браузере (версия 1) при первом открытии пересоздаются автоматически.

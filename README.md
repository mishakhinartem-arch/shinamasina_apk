# «Шинамашина» — веб-версия кассы (демо-прототип)

Демо-версия, **данные вымышлены**. Всё хранится в `localStorage` браузера (ключ `shinamashina_web_demo_v1`).
Реальный Supabase, APK, Эвотор и данные клиентов не используются. SMS/MAX/Telegram не отправляются — напоминания только имитируются.

## Страницы
| Файл | Что это |
|---|---|
| `index.html` | Касса (планшет Teclast M50, горизонтально; терпимо в портрете и на телефоне) |
| `owner.html` | Страница владельца для iPhone: отчёты, прибыль, ЗП за открытую смену (по PIN) |
| `book.html` | Онлайн-запись для клиентов |
| `client.html` | Анкета клиента с согласием на ПД |
| `queue.html` | Планшет живой очереди для клиентов: ввод госномера → талон (в сезон) |

Демо-PIN владельца: **1234** (подсказка показана на экране ввода). Сброс: Админка → Настройки → «Сбросить демо-данные».
Запуск локально: `python3 -m http.server 8765` в этой папке → http://localhost:8765/ . После первой загрузки по https работает офлайн (service worker).

## Модули (переносятся в APK/WebView как есть)
Логика без DOM (`js/`): `core` (время, формат, госномер), `store` (состояние), `prices-data` (= prices.js из кассы 14.7), `prices` (каталог, «Частые»),
`cart` (надбавка +20%, скидки, лимит), `orders` (заказы и статусы), `shift` (смена, ящик, инкассация), `payroll` (ЗП, расчётный лист),
`warehouse` (склад, нормы, автосписание; грузики — коробками), `storage` (хранение шин, тариф), `booking` (запись, вместимость слотов), `queue` (живая очередь, посты, ожидание), `printer` (ESC/POS, CP866, мост `window.AndroidPrinter` в APK), `products` (товары, остатки, списание), `paint` (наряды покраски дисков), `reminders` (напоминания о записи за 24 ч / 2 ч), `reports` (расходы, отчёты, прибыль), `excel` (прайс ⇄ xlsx), `seed` (демо-данные), `docs` (сгенерирован из `docs/*.md`: договор хранения и согласие на ПД), `consent`.
Интерфейс (`ui/`): `base` (окна, клавиатура госномера, нумпад, PIN, печать), `kassa`, `shift`, `clients`, `storage`, `warehouse`, `bookings`, `admin`, `report-view`, `paint` (приём/выдача покраски, акт), `catalog` (Админка → «Услуги и товары»).
PWA: `manifest.webmanifest` (display fullscreen), `manifest-queue.webmanifest`, иконки `icons/` (генерирует `tools/make-icons.js`), `sw.js` (кэш v3).
SheetJS лежит локально: `vendor/xlsx.full.min.js`.

## Решения Артёма (18.11.2026), внесены
1. Скидка постоянному 10% не входит в лимит — лимит только на ручную скидку кассира.
2. Хранение — фиксированный тариф (Админ → Настройки → «Хранение — тариф»): ₽ за комплект 4 шины за сезон (6 мес.) по радиусу + доплата за диски; другой срок / число шин — пропорционально, до 50 ₽. **Демо-значения примерные.** При приёме цена подставляется сама; изменить вне тарифа — только по PIN. Хранение можно добавить в чек заказа: скидки (постоянному и ручная) на него не действуют.
3. Хранение не входит в базу процента мастеров (и в «Услуги» в отчётах — идёт отдельной строкой).
4. Грузики (набивные и клеевые) не списываются по нормам с машины — учёт коробками: приход коробками, «📦 Взять коробку» (списание целой коробки), инвентаризация в коробках.
5. Договор хранения и согласие на ПД — **шаблоны, юристом не проверены**: в акте/печати хранения, в анкете `client.html`, в `book.html` и в форме клиента (раскрывающийся полный текст).

## Правки 18–19.11.2026, внесены
1. R14–R16: тип «Коммерческий» (колонки R14C/R15C/R16C), на R16 — «Газель». Кнопки типа видны только там, где есть цены.
2–3. Сезон: живая очередь с планшета `queue.html` (номер с №1 каждый день; тот же номер в тот же день — тот же талон). 3 поста: 2 под онлайн-запись, 3-й — живая очередь; примерное ожидание = (машин впереди + занятые посты × 0,5) × среднее время / постов очереди. Настройки — Админка → Настройки → «Сезон и посты».
4. Сетевой принтер: IP/порт и «Тестовая печать» в настройках. В браузере печатать по TCP нельзя — честное сообщение и образец ленты; печать — только из APK (`window.AndroidPrinter.print(ip, port, base64)`, ESC/POS, CP866). На реальном принтере не проверено.
5. Предупреждения «заканчивается» убраны с кассы — только на `owner.html` (склад + товары).
6. «Выдать коробку» → «Взять коробку».
7. Итого и корзина закреплены внизу кассы; дубль «Принять машину» убран.
8. Полный экран: кнопка ⛶ в шапке, manifest display fullscreen, установка как приложение (Админка → Настройки).
9. Покраска дисков — отложенный наряд: колпачки, резина (+марка), правка (кол-во, сумма), любые услуги прайса; при приёме без оплаты, наряд в «Машины → В покраске»; при выдаче один чек на всё. Акт приёма на печать; у владельца — кто сдал и сколько должен. Скидки на наряд не применяются; выручка — услуги (в базе % мастеров) — **уточнить у Артёма**.
10. Напоминания о записи за 24 ч и 2 ч: канал (MAX/Telegram/SMS) и согласие у клиента; запускаются автоматически, пока открыта касса или страница владельца; журнал — у владельца. В демо — имитация.
11. Владелец по PIN (Админка → «Услуги и товары»): цены встроенных услуг, скрыть/показать, свои услуги (фикс / по радиусу и типу / цена на кассе), товары (продажа, закупка, остаток, мин.). Товар в чеке без скидок, не в % мастеров, при оплате списывается со склада.

Старые демо-данные в браузере (версии 1–2) при первом открытии пересоздаются автоматически.
